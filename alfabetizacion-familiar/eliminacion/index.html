Eliminación de datos

Una familia puede solicitar la eliminación de los datos, mensajes y materiales identificables enviados al número de WhatsApp del Proyecto Alfabetización Familiar.

Cómo solicitarla

  1. Enviar un correo a celiarosemberg@gmail.com.
  2. Usar como asunto: Eliminación de datos — Proyecto Alfabetización Familiar.
  3. Indicar el número o identificador de WhatsApp utilizado.
  4. Indicar, si se conoce, el código de familia, sala o jardín.
  5. Aclarar si se solicita eliminar toda la información o solamente determinados archivos.

No enviar fotografías de documentos de identidad.

No enviar contraseñas ni códigos de verificación.

Qué ocurre después

  • El equipo puede realizar una comprobación razonable para impedir que otra persona elimine datos ajenos.
  • Se eliminarán el número de WhatsApp cifrado, los mensajes, los archivos y las copias administrativas identificables bajo control del proyecto.
  • Los datos ya disociados de manera irreversible pueden no ser localizables individualmente.
  • La solicitud no afecta la relación con el jardín, la sala ni las maestras.
